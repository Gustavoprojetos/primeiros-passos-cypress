# My Cypress Automation

This project utilizes Cypress to automate the testing of a longi feature and a user update feature. Cypress is a JavaScript besed end to end testing framework that allows developrs to write tests and execute then in a real browser.

## Instalation
```bash
npm install
```
> **NOTE:**
> 
> It is necessary to have **node** installed

## Running
```bash
# You open the Cypress UI
npx cypress open

# Run the automation by command line
npx cypress run
```
